# offers module

Provider-owned promotional offers backed by `marketing.offers`.

## Routes

- `/providers/:providerId/offers` — provider offer management.
- `/admin/offers` — global moderation for `CONTENT_ADMIN`, `ADMIN`, or `SUPERADMIN`.

The admin catalog supports search, provider/status filters, activation, featured placement, immediate expiration, usage visibility, and reasoned audit events in `provider_portal.admin_catalog_actions`.
