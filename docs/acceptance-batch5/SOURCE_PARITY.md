# Source Parity Note

The latest textual/file-library evidence is Staff Operations Batch 4, but its source ZIP is not available as mounted bytes in this runtime. The local editable baseline is rc12.

This batch reconstructs the explicitly documented Batch 4 staff availability, staff booking, booking-management and active-ownership protections before adding Staff Reviews, user-owned staff media, credentials and the field-ownership matrix.

Do not treat migration/file counts in this package as proof of exact parity with the unavailable Batch 4 source archive. The latest source evidence reported 60 modules / 620 source files / 88 migrations; this reconstructed tree reports 60 modules / 595 TS/TSX files / 85 migrations.
